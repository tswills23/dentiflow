# Output format — how every ad is delivered

Trevor should be able to paste this straight into Ads Manager. No commentary above it, no
"here's what I came up with." The ad, then the reasoning, in that order.

---

## Per-ad block

```
## Ad [N] — "[working name]"

**Cell:** [callout type] × [value element] × [WHO] × [WHEN] · enters at [awareness stage]
**Proof leaned on:** [which locked fact does the heavy lifting]
**Kill condition:** [what result would tell us this angle is dead]

---

**HEADLINE** (≤40 chars)
[headline]

**PRIMARY TEXT** (230–250 words, 13-beat)
[body copy]

**DESCRIPTION**
[one line]

**CTA BUTTON:** Learn More | Apply Now | Sign Up

**CREATIVE DIRECTION**
- Format: [1:1 static / 4:5 / 9:16 / video]
- HERO line on image: [big on-image copy — must read at thumbnail size, sound off]
- SUB: [smaller supporting line]
- Visual: [direction]
- Why this visual is conceptually separate from the others in this batch: [one line]
```
